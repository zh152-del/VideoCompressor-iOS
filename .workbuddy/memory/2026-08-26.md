# 2026-08-26 工作日志

## iOS 视频压缩 App（VideoCompressor-iOS）包体与 Bug 核查

### 包体核查结论
- 用户疑问：IPA 只有 ~382KB 是否找错文件。结论：文件正确，未签名、合法。
- 原因：IPA 是 zip，382KB 为压缩体积；解压后 1.8MB，ARM64 二进制本体 1.7MB。体积小因为 SwiftUI/AVFoundation/PhotoKit 均为 iOS 系统框架，不打包进 App。
- 校验：无 `_CodeSignature`、无 `embedded.mobileprovision` = 确为未签名；Mach-O `cpu=0100000c` = ARM64。

### 查出并修复的真实 Bug
1. 【严重】`PhotoLibraryService.saveVideo` 在首次使用（status=.notDetermined）时未调用 `requestAuthorization()` 就直接抛 `photoPermissionDenied` → 首次“保存到照片”必失败且无系统弹窗。已修复：先 `requestAuthorization()` 再判断。
2. 【中等】`ResultView.isSaved` 用 `savedID != nil` 判定，saveVideo 在 fetch 异常返回 "" 时被误判为已保存。已改为 `!(savedID ?? "").isEmpty`。
3. 【设计待定】`ExportPresetEngine` 三档（quick/balanced/high）都是“取不超过源分辨率的最低档”，对 1080p 源 quick→540p、balanced/high→480p，区分度丢失。已列出待用户拍板，未改。
4. 【澄清非 bug】`.readWrite` 权限看似过度，但因需求要“保存后删原片”，删除属 modify 操作必须 readWrite 级，故保留。
5. 【轻微】`TranscodeEngine` 用 `startSession(atSourceTime:.zero)`，源首帧 PTS>0 时可能留小段黑场，罕见，暂未改。

### 验证
- 两修复提交 `66e5eff`，CI run `32966696764` 绿色通过（macos-15/Xcode16.4）。
- 新未签名 IPA 已覆盖 `unsigned_ipa_artifact/VideoCompressor-unsigned.ipa`（383,317 字节，ARM64，未签名）。
- 仍需用户在真机用爱思重签验证运行时表现（压缩画质/UI/删原片）。

## 第二轮修复（用户真机反馈：显示比例不对 + 保存闪退）

### 真机环境
- iPhone 14 Pro Max，iOS 18.3.1，系统语言中文。

### 修复①：全面屏比例不对（letterbox）
- 根因：工程无 LaunchScreen，Info.plist 里 `UILaunchScreen` 为空字典 → iOS 以兼容模式运行，14 Pro Max 上下出现大段空白。
- 修复：新增 `VideoCompressor/Resources/LaunchScreen.storyboard`（含“视频压缩”标题、systemBackgroundColor），Info.plist 改 `UILaunchStoryboardName = LaunchScreen`，移除空 `UILaunchScreen`。
- 验证：新 IPA 内 `.app` 已含 `LaunchScreen.storyboardc`，编译通过。

### 修复②：点击“保存到照片”闪退
- 改动：`PhotoLibraryService.saveVideo` 改用 `PHAssetCreationRequest.placeholderForCreatedAsset.localIdentifier` 获取保存后的资源 ID（替代保存后同步反查相册，后者不可靠且易触发 UI 线程阻塞）；并把 `performChanges` 的 completion 内 `cont.resume` 统一用 `DispatchQueue.main.async` 派发到主线程（避免真机线程/隔离问题导致崩溃）。`deleteOriginal` 同样处理。
- 编译坑：`MainActor.run` 是 async 函数，不能放在非 async 的 completion 闭包里（报 'async' call in a function that does not support concurrency），改用 `DispatchQueue.main.async`。
- 验证：CI run `32969657649` 绿色通过，新 IPA（388,472 字节，ARM64，未签名）已覆盖根目录 `VideoCompressor-unsigned.ipa`。
